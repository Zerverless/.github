# .github

Category: **Core**

This repository controls the public GitHub organization profile for
`github.com/zerverless`, and hosts org-wide default community health files
(Code of Conduct, Security Policy, Contributing Guide, issue templates) that
apply to any repository in the organization that doesn't define its own.

## What lives here

```
.github/
├── profile/README.md         # Rendered on github.com/zerverless
├── CODE_OF_CONDUCT.md         # Org-wide default
├── SECURITY.md                 # Org-wide default
├── CONTRIBUTING.md              # Org-wide default
├── ISSUE_TEMPLATE/                # Org-wide default templates
└── workflow-templates/              # Reusable GH Action templates (not enabled yet — no CI)
```

## Not responsibilities

No infrastructure, no product logic, no application code, no billing, no
deployment code. If you're looking for any of that, see the relevant repo
in the [org profile](profile/README.md).

## Status

Defined.
